# Clyde — Technical Documentation

This folder contains technical documentation for my CYBR 4790 cybersecurity home lab.

As the project develops, I will add network diagrams, configuration notes, troubleshooting records, and security monitoring investigations.

## Planned Documentation

- **Network Architecture:** Proxmox virtual networking, pfSense firewall, and isolated lab subnet.
- **Windows Domain:** Active Directory, DNS, DHCP, and Windows 11 domain integration.
- **Linux Administration:** Ubuntu Server configuration and remote administration.
- **Security Monitoring:** Wazuh deployment, endpoint monitoring, and security event investigations.
- **Troubleshooting:** Problems encountered during implementation, how I investigated them, and what I learned.

Documentation will be added as each part of the project is completed and reviewed for publication.
